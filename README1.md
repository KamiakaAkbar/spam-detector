# 📩 Real-Time Spam Message Classifier

This project uses Machine Learning (Naive Bayes + TF-IDF) to classify SMS messages as **Spam** or **Not Spam** using a simple real-time Streamlit interface.

## 🚀 Features
- Live text input and prediction
- Built with Scikit-learn and Streamlit
- Lightweight and fast

## 📦 How to Run

### Step 1: Install packages
pip install -r requirements.txt
### Step 2: Train the model
python train_model.py
### Step 3: Run the app
## 🔗 Dataset Source
- [SMS Spam Dataset (UCI)](https://archive.ics.uci.edu/ml/datasets/sms+spam+collection)
